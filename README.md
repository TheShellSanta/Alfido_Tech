## 🔍 Task 1 – Reconnaissance & Vulnerability Scanning

### 🎯 Objective

Identify exposed services, open ports, and potential vulnerabilities in a target environment.

### 🧪 Activities

* Port scanning using Nmap
* Service enumeration
* Vulnerability scanning using Nikto/OpenVAS

### 📊 Key Outcomes

* Identification of active services
* Initial attack surface mapping
* Detection of potential vulnerabilities

### 🌍 Industry Relevance

Forms the **foundation of penetration testing**, enabling informed exploitation strategies.

---

## 🌐 Task 2 – Web Application Security Testing

### 🎯 Objective

Assess web applications for common vulnerabilities:

* Cross-Site Scripting (XSS)
* SQL Injection (SQLi)

### 🧪 Activities

* Intercepting HTTP requests using Burp Suite
* Manipulating inputs to test for vulnerabilities

### 📊 Key Outcomes

* Identification of insecure input handling
* Demonstration of exploitation vectors
* Suggested mitigation strategies

### 🛡️ Security Practices Highlighted

* Input validation & sanitization
* Parameterized queries
* Secure coding principles

### 🌍 Industry Relevance

Web vulnerabilities remain a **primary attack vector in real-world breaches**.
